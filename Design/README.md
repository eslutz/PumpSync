# PumpSync design

The editable PumpSync iPhone design is maintained in Sketch at [`PumpSync iPhone.sketch`](PumpSync%20iPhone.sketch).

The private Sketch Workspace document is available at [PumpSync iPhone](https://www.sketch.com/s/d8efa2d8-b83a-4890-888b-0f82cec04b4e).

The document contains the current iPhone screens, representative states, reusable components, and accessibility layouts. App source is the reference for current behavior and copy. Simulator-only and Apple-owned system surfaces may have fidelity limits in the editable design.

The Sketch file is design material only; it is not included in the iOS app bundle.
